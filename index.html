Privacy policy

How this tool handles data.

This is an independent Discord ID lookup tool. It is not affiliated with Discord Inc.

What we collect

Lookups use public APIs (e.g. japi.rest or similar) and Discord’s CDN. We do not operate a backend that stores your Discord ID lookups, email, or IP for this static page.

Local storage

Settings (font, background, music preferences), recent lookup history, and any uploaded images/audio stay in your browser’s localStorage / memory only. Clearing site data removes them.

Discord OAuth

If you use “Sign in with Discord”, Discord’s own privacy policy applies. Scopes requested may include identify, email, and guilds.join. Revoke access anytime in Discord → Settings → Authorized Apps.

Third parties

Profile and asset requests go to third-party public APIs and Discord’s CDN. Their terms and logging apply.

Contact

This is a demo-style tool. For production deployments, replace this policy with one that matches your hosting and analytics setup.

Terms of use

Simple rules for using this tool.

By using DiscordLookup you agree to the following.

Public data only

The tool displays information Discord makes available via public profile endpoints and Snowflakes. It cannot and must not be used to obtain private data (email, phone, IP, DMs, tokens, linked accounts).

Acceptable use

Do not use this tool to harass, stalk, or dox anyone. Do not automate mass lookups against third-party APIs in a way that violates their terms or Discord’s Terms of Service.

No warranty

Not affiliated
